# 📅 Календарь с управлением событиями

Адаптивный веб-календарь с возможностью добавлять, редактировать и удалять события. Список событий можно сворачивать/разворачивать. Проект доступен по ссылке и корректно отображается на любых устройствах.

## ✨ Функциональность

- 📆 Просмотр календаря (месяц/неделя/день)
- ➕ Добавление событий с указанием времени и описания
- ✏️ Редактирование существующих событий
- 🗑️ Удаление событий
- 📋 Сворачиваемый список событий
- 📱 Полностью адаптивный дизайн (мобильные, планшеты, десктоп)
- 🔗 Доступ по прямой ссылке

## 🛠️ Технологии

- HTML5
- CSS3 (Flexbox/Grid, медиазапросы)
- JavaScript (нативный)
- LocalStorage (сохранение событий)
